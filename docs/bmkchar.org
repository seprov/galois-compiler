LonestarGPU Benchmark Characterization (from a compiler's perspective)

* BFS

  Synchronous

  Worklist AllNodes(Graph)

  ForAll Node in AllNodes
      Worklist EdgeList = Expand(Node.Edges)
      ForAll Edge in EdgeList
           If Edge.Dest.Weight == INFINITY:
	       Edge.Dest.Weight = Level [atomic]
	       Push Edge.Dest onto Next

Here Operator is (Node, Edge) [note ForAll loops]

Irregular Functions are Node expansion and Edge Expansion

Atomic Update and Push are also irregular

* SSSP

  Synchronous

  ForAll Node in AllNodes
      Worklist EdgeList = Expand(Node.Edges)
      ForAll Edge in EdgeList
           If Node.Weight + Edge.Weight < Edge.Dest.Weight:
	       Atomic Edge.Dest.Weight = Node.Weight + Edge.Weight
	       Push Edge.Dest onto Next
